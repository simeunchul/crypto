Crypto — 익절 룰 walk-forward 검증

생성: 2026-05-30 · 관련 데이터: data/backtest_tp_sweep_365d_20260530_153557.json, data/backtest_tp_walkforward_365d_20260530_155806.parquet

한 줄 결과. 사용자 질문 — "AVAX SHORT 가 미실현 +$315 까지 갔다가 +$238 로 $77 반납했다. 익절 룰을 넣으면 막을 수 있는가".
검증한 답: 평균적으론 약간 좋아지지만 (Sharpe +0.27, 단순 채택 권장 못 함). 365일 in-sample 스윕에선 단계적 trail 압축(tiered+3%) 이 baseline 대비 Sharpe +0.21 우세였으나, 30일 비중첩 윈도우 198개로 walk-forward 검증 결과 강한 추세장(STRONG_TREND) 91개 윈도우에선 승률 42.9% — 평균을 깎는 구간. 약한 추세·횡보에선 승률 60% 대로 강함. 즉 regime-dependent rule — 시장 국면 감지 없이 일괄 적용하면 강추세장에 손해. 권장: 즉시 채택 X, 4종(SUI, LINK, NEAR, ADA)은 baseline 유지 + 나머지 14종만 tiered+3% 적용의 부분 채택 또는 regime detector 도입 후 동적 적용.

0. 이 보고서의 위치 — 지금까지 의사결정 흐름

봇은 한 번에 만들어진 게 아니라 지난 1주일간 backtest 결과를 보고 단계별로 좁혀온 결과물이다. 본 보고서는 그 마지막 미세조정 단계의 검증이다. 이전 결정들을 모르면 "왜 baseline 이 baseline 인가"가 안 보이므로 요약한다.

파란 점 = 결정 / 추가, 빨간 점 = 문제 해결, 노란 점 = 현재 검증. 각 단계 sharpe 는 측정 기간·종목셋 다르므로 직접 비교 불가 (맥락만).

흐름의 핵심. 매 단계가 직전 결정을 뒤집은 게 아니라 그 위에 한 칸씩 쌓은 구조. baseline_trail2 (Sharpe 4.10) 는 위 결정들의 누적 결과지 임의의 시작점이 아니다. 본 검증은 그 baseline 을 깨려는 시도였고, 평균은 깰 수 있지만 모든 시장 국면에서 깰 수는 없다는 결론.

1. 왜 이 검증을 했는가

실제 운영봇이 AVAX 를 SHORT (entry $9.8175) 로 보유 중인 상황. 시세가 intraday $8.65 까지 내려가 미실현이익이 +$315 가까이 갔다가, 다시 $8.93 으로 반등하며 +$238 (약 $77 반납) 으로 줄어들었다. 사용자가 "지금처럼 trail-stop 만 쓰면 이런 반납을 못 막는다. 익절 기준을 명확히 잡고, 필요시 재진입 하는 게 낫지 않냐" 라고 질문.

현행 trail-stop (옵션 Z) — 4h 봉 마감 close 가 high_water (LONG) / low_water (SHORT) 대비 2% 반대로 가면 청산. AVAX 의 경우 low_water $8.813, trigger $8.989. 현재 mark $8.926 은 trigger 까지 +0.71% 남음. backtest sweep 우승 구성 (Sharpe +2.76 검증).

4. 그러나 in-sample 만으로 채택하면 위험

오버피팅 (overfitting) 위험. 365일 전체로 가장 잘 맞는 룰을 골랐기에, 그 룰이 365일 안의 특정 시장 국면 (예: 횡보가 많았던 시기) 에만 강할 수 있다. 30일 비중첩 윈도우 11개로 분해하여 (윈도우 × 18종 = 198 표본) 시간 / 국면별 robustness 를 본다.

윈도우 시간순 — 오버피팅 검출

2025-05 ~ 2026-04 의 11개 30일 윈도우. 한 윈도우만 마이너스(W1, -0.20). 시간 흐름으로 명확한 우상향/우하향 패턴 없음 → 오버핏의 강한 신호는 아님. 단 STRONG_TREND (빨강) 윈도우 8개 중 3개는 △ ≤ +0.02 — 강추세장에서 우세가 미미.

핵심 단서. tiered+3% 는 횡보·약한 추세에선 강하고 강한 추세에선 약함. 단순 채택 시 BTC 가 100일 연속 +30% 같은 강추세 구간에 손해.

왜 그런가 — 직관

강한 추세장: 진입 → +3% 빠르게 도달 → trail 1% 로 압축 → 정상적 단기 retracement (-1.5%) 도 trigger → 청산 → 같은 방향 신호로 차단 → 큰 추세의 후반 30~50% 놓침 결과: baseline 대비 손해 횡보·약한 추세장: 진입 → +3% 도달 → trail 1% 압축 → 작은 반전에 빨리 청산 → +2%~+3% 안전 확보 → 큰 추세 없으므로 후행 손실 없음 결과: baseline 대비 우세

종목별 — 일관성 검사

18종 중 14종이 우세, 4종(ADA, SUI, NEAR, LINK)은 손해. AVAX 가 가장 큰 수혜자 (사용자 질문의 원본). LINK·NEAR 는 강추세 비중 높았던 종목.

6. 결론 — 무엇을 어떻게 할 것인가

즉시 채택은 권장하지 않음. 평균 (+0.27 Sharpe) 은 살아있지만 — 승률 52.5% 로 동전던지기에 가깝고, STRONG_TREND 91 윈도우에선 승률 42.9% (baseline 이 더 자주 이김). 운영봇에 일괄 적용 시 다음 강한 추세장에 손해.

옵션 A — 그대로 baseline 유지 (가장 안전)

현행 trail-only (Sharpe +2.76 검증) 가 가장 robust 한 단일 룰. AVAX 의 $77 반납 같은 비용은 winners run 의 정상 가격으로 받아들이고, 큰 추세 후반을 잡는 이익을 우선시.

옵션 B — 부분 채택 (실용적)

walk-forward 에서 winner 14종에만 tiered+3% 적용. baseline 유지: ADA, SUI, NEAR, LINK. 운영봇 사이드에서 종목별 trail 룰 분기 필요 (configurable per-symbol trail).

종목군적용 룰평균 ΔSharpe

옵션 C — Regime detector + 동적 룰 (이상적, 복잡)

최근 N일 buy&hold |수익률| 로 시장 국면 분류 후 룰 전환:

최근 30일 |bnh%| ≥ 15 → STRONG_TREND → baseline_trail2 (winners run 유지) 6% ≤ |bnh%| < 15 → WEAK_TREND → tiered_at+3% (큰 이익 보호) |bnh%| < 6 → RANGE → tiered_at+3% (이익 빨리 잠금)

구현은 30일 lookback price diff 한 줄. 단 regime 분류기 자체가 lag 가 있고, 분류 경계 (15%, 6%) 가 새 hyperparam 이 되어 또 다른 오버피팅 위험. 추가 검증 필요.

7. AVAX 케이스 — 검증 결과 재해석

사용자가 본 "$77 반납" 은 backtest 기준으로 보면 AVAX 가 tiered+3% 적용 시 가장 수혜를 받는 종목 (ΔSharpe +0.76). 즉 현재 AVAX 한 종목에 한해서는 tiered 가 명확히 좋다. 하지만 같은 룰을 모든 종목에 일괄 적용하면 ADA, SUI, NEAR, LINK 같은 종목에서 손해 — 18종 평균을 깎는다. 옵션 B (종목별 분기) 가 데이터적으로 가장 합리.

8. 한계 / 다음 단계

  • 기간 한정 — 검증 365일은 2025-05 ~ 2026-05. 다른 시기 (예: 2022 bear) 에선 결과 달라질 수 있음. 다년 walk-forward (3-5년) 권장.
  • 비용 모형 단순 — 4bps/side 만. funding rate, 슬리피지 미반영. 실제 live 수익률은 더 낮음.
  • regime 분류기 미구현 — 옵션 C 의 lookback window 와 분류 경계는 또 다른 hyperparam. 별도 walk-forward 로 결정 필요.
  • 옵션 B 운영봇 통합 — 종목별 trail 설정을 받는 BotConfig 확장 필요 (현재는 전역 trail_pct 1개).
TL;DR (비전공자용 요약)
"AVAX 미실현 이익이 $315 → $238 로 줄어든 건, 익절 기준을 정하면 막을 수 있을까?" 가 질문.
검증 한 마디: "AVAX 만 보면 막을 수 있고, 18종 전체로는 강한 추세장에 손해. 단순 채택 X, 종목별 선별 적용 권장".

- 후보 룰 14개 (단순 trail / 단계 trail 압축 / 부분 익절 / 전량 익절 × 임계값 3~15%) 를 18종 × 365일 백테스트로 비교.
- in-sample (전 기간 평균) 에선 단계 trail 압축 (tiered+3%) 이 현행 대비 Sharpe +0.21 우세.
- 30일 단위 198개 윈도우로 쪼개 다시 보니, 강한 추세장 91 윈도우에선 오히려 더 자주 손해 (승률 42.9%). 횡보·약한 추세 윈도우에선 60% 대로 강함.
- 즉 이 룰은 "시장 상황에 따라" 효과가 갈리는 regime-dependent rule. 그대로 켜면 다음 강추세장에 baseline 보다 손해.
- 실용적 권장: 14개 종목엔 단계 trail 압축 적용, 4개 (ADA·SUI·NEAR·LINK) 는 현행 유지. 이게 평균 +0.39 Sharpe.
- AVAX 한 종목에 대해선 단계 trail 압축이 최고의 수혜 (Sharpe +0.76). 사용자 직관은 데이터적으로 맞았다 — 단지 일괄 적용이 아니라 선별 적용이 필요할 뿐.

trailing stop (trail) 매수 후 최고가 (또는 SHORT 의 경우 최저가) 대비 X% 반대로 가면 자동 청산하는 룰 현행 운영봇이 사용하는 청산 메커니즘. 기준선.
옵션 Z trail 판정을 봉 중간 가격이 아닌 봉 마감 종가 (close) 만 사용. backtest 일치성을 위한 단순화 현재 운영봇 채택. AVAX intraday $8.65 가 trigger 못 한 이유.
MA crossover 단기 이동평균 (fast MA) 이 장기 이동평균 (slow MA) 을 위로 뚫으면 LONG, 아래로 뚫으면 SHORT 신호. 추세추종의 기본형 진입 신호. 운영봇은 4h × 12/48 (= 2일/8일 평균).
Sharpe ratio 수익을 변동성으로 나눈 위험조정 수익률. 높을수록 같은 위험으로 더 많은 수익. 일반적으로 1.0 이상이면 우수, 2.0 이상은 매우 우수 전략 비교의 단일 지표. 룰 채택 의사결정의 핵심 metric.
Max drawdown (MaxDD) 자본곡선의 최고점 대비 최대 하락 폭 (%). "최악의 시점 손실" 위험 측면. tiered+3% 가 baseline 대비 약간 줄임 (-9.19 → -8.96).
walk-forward 시간을 따라 여러 윈도우로 쪼개 각각 평가, "한 번 잘 맞은 게 운인지 일관된 우세인지" 검증 in-sample 의 +0.21 이 시간/국면 across robust 한지 확인. 결론: 부분적으로만.
in-sample / out-of-sample in-sample = 룰을 고르는 데 쓴 데이터. out-of-sample = 그 룰을 처음 보는 데이터. 후자에서도 좋아야 진짜 robust 365d 전체 (in-sample) 에서 좋아도 30일 윈도우 일부 (out-of-sample 비슷) 에서 무너지면 오버핏 의심.
overfitting (오버피팅) 특정 데이터에 너무 잘 맞춰서 새 데이터에선 실패하는 현상. backtest 의 가장 큰 함정 tiered+3% 가 "365일이라는 우연한 시기" 에만 좋은 건지 확인이 핵심 동기.
regime / 시장 국면 시장이 처해있는 상태. 본 분석은 30일 buy&hold |수익률| 로 STRONG_TREND (≥15%), WEAK_TREND (6~15%), RANGE (<6%) 로 분류 tiered+3% 가 RANGE 에 강하고 STRONG_TREND 에 약하다는 결정적 발견.
tiered trail (단계적 trail 압축) 진입 후 일정 이익 (예: +3%) 도달 시 trail 폭을 좁히는 룰 (예: 2% → 1%). "이익 보호 모드 진입" 본 분석의 최우수 후보. 평균 우세, but regime dependent.
partial TP / hard TP partial = 이익 도달 시 포지션 일부 (예: 50%) 청산, hard = 전량 청산. 둘 다 winners run 을 끊는 효과 backtest 결과 둘 다 baseline 보다 나쁨. winners run 의 가치를 정량적으로 보여줌.
winners run "이긴 트레이드를 빨리 청산하지 말고 끝까지 가져가라" 는 추세추종의 격언. trail-stop 의 철학적 배경 왜 hard_tp_5% 가 Sharpe 4.1 → 2.5 로 박살나는지 설명. 큰 추세의 후반부가 평균 수익의 큰 부분.
low_water / high_water SHORT 포지션의 최저 종가 (low_water) / LONG 의 최고 종가 (high_water). trail trigger 의 기준점 AVAX 의 경우 low_water = $8.813. trigger = $8.813 × 1.02 = $8.989.
buy&hold (bnh) 기간 시작 시 매수해 끝까지 보유했을 때의 수익률. 시장 자체 움직임 windows 의 |bnh%| 로 시장 국면 분류.
non-overlapping window (비중첩 윈도우) 시간을 겹치지 않게 잘라 만든 검증 구간. 30일 × 11개 = 330일 (≈ 365) 각 윈도우가 독립 표본이 되어 통계적 분산 추정에 적합.
